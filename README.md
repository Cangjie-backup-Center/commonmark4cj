## 介绍

用于根据CommonMark规范（以及一些扩展）解析和呈现Markdown文本。

### 特性

- 🚀 解析markdown文本

- 🛠️ Node树状结构

- 💡 遍历/渲染Node树

## 软件架构

### 源码目录

```shell
├── entry                  # 示例模块
├── markdown_hybrid        # markdown互操作模块
└── README.md              # 整体介绍
```
